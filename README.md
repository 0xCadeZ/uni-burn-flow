# What kind of trading funds the UNI burn?

Reproducible analysis of Uniswap protocol revenue (UNI burn funding) on Robinhood Chain,
August to October 2026, from public endpoints only. Write-up: [POST.md](POST.md). Numbers and
reconciliations: [FINDINGS.md](FINDINGS.md). Charts: [charts/](charts/).

## Headline numbers (Robinhood Chain, 1.19M sampled Uniswap v3 swaps)

| | Share of volume | Share of protocol fee |
|---|---|---|
| Memecoin / other pools (mostly 1% tier) | 13% | 64% |
| Tokenized stocks and ETFs (Robinhood registry) | 14% | 23% |
| Crypto majors (WETH/USDG, 0.01% tier) | 72% | 12% |

| Transaction class | Robinhood Chain | Ethereum mainnet |
|---|---|---|
| Single swap via shared router | 58% | 61% |
| Round trip (atomic arbitrage) | 30% | 26% |
| Multi-hop | 9% | 13% |
| Private bot, direct | 4% | 0% |

Sampled protocol fees scale to $15.0M for Aug–Oct against DefiLlama's $14.7M (+2%).

## Reproduce

Python 3.11+, standard library only. No API keys.

```sh
python3 -I scripts/01_fee_series.py        # DefiLlama revenue by chain/version -> data/daily_*.csv
python3 -I scripts/02_sample_swaps.py      # Robinhood Chain public RPC, 84 windows -> data/samples/ (~400 MB, ~30 min)
python3 -I scripts/03_classify.py          # classify + price -> data/classify_output.txt
python3 -I scripts/04_mainnet_baseline.py  # Ethereum mainnet, 2 days -> data/mainnet/
python3 -I scripts/05_charts.py            # charts/*.html (render to PNG with any browser)
```

`02_sample_swaps.py` also needs `data/robinhood_v3_pools.json` (all v3 PoolCreated events from the
factory, 449,704 pools); it is regenerated by the pool-list snippet in FINDINGS.md or on request.

Raw samples are not committed. `data/robinhood_window_pair_class.csv` is the per-window,
per-pair, per-class aggregate of the full classified sample (every number in the post derives from it).
